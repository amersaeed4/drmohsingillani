# WordPress import archive

`media-library/` holds every file from the old WordPress media library (67 files, downloaded from
drmohsingillani.com). Most are unused Betheme demo graphics. Pick from here if you need an image
again, then upload it through Admin → Pages → (page) → Page Media.

Images that the old site referenced from its dev host (demo.itlinks.com) no longer exist there, so
those pages have no photo until you upload one.
